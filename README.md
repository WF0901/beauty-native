# Beauty SaaS MVP

美业/到店服务 SaaS 原型，覆盖平台、商户、门店员工、技师和顾客小程序视角。

## 开发

```bash
pnpm install
pnpm run dev
```

## 构建

```bash
pnpm run build
```

## 原型验证

先启动预览服务：

```bash
pnpm run preview
```

再运行验证脚本：

```bash
node verify_prototype.mjs
```
